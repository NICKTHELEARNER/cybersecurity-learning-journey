## Program Structure

I learned how a basic C program is structured and the role of the `main()` function.

I also learned that C is case-sensitive and that code enclosed by `{}` forms a block.

## Input and Output

I practiced using:

* `printf()` to display information
* `scanf()` to read values from the user

I also learned about format specifiers such as:

* `%d`
* `%u`
* `%hd`
* `%ld`
* `%lu`

## Variables and Integers

I learned that variables are used to store values of specific types.

I practiced declaring variables, assigning values to them, performing arithmetic operations, and using the result of one calculation to initialize another variable.

## Type Sizes

I learned how to use `sizeof` to determine the size of a type or expression in bytes.

This introduced me to the idea that different C types have different representations and sizes.

## Signed and Unsigned Integers

I started studying the difference between signed and unsigned integer types.

This led me to investigate the limits of integer types and what happens when an unsigned integer reaches its maximum value.
